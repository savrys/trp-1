# Сервис аренды велосипедов

## Назначение

Приложение предназначено для автоматизации процесса аренды велосипедов:
ведения парка велосипедов и станций проката, регистрации пользователей,
оформления аренды, расчёта стоимости с учётом скидки, а также сохранения
данных между запусками программы.

## Описание предметной области

- регистрация пользователей (имя, телефон);
- ведение списка станций проката (название, адрес, вместимость);
- ведение парка велосипедов (тип, цена за час, станция, статус);
- выбор доступного велосипеда для аренды;
- указание количества часов аренды;
- расчёт стоимости аренды в зависимости от типа велосипеда и времени;
- применение скидки при длительной аренде;
- расчёт времени начала и окончания аренды;
- завершение и отмена аренды;
- поиск аренд по пользователю;
- формирование статистики по арендам;
- сохранение и загрузка данных в JSON-файлах.

## Основные сущности

| Сущность   | Описание                                                              |
|------------|-----------------------------------------------------------------------|
| Велосипед  | тип (городской, горный, детский), цена за час, станция, статус         |
| Пользователь | имя, телефон, дата регистрации                                      |
| Станция    | название, адрес, вместимость                                          |
| Аренда     | велосипед, пользователь, станция, время начала/окончания, стоимость, статус |

## Тарифы

| Тип велосипеда | Код | Цена за час |
|----------------|-----|-------------|
| Городской      | 1   | 200 руб.    |
| Горный         | 2   | 300 руб.    |
| Детский        | 3   | 150 руб.    |

## Система скидок

| Количество часов | Скидка |
|------------------|--------|
| от 5 до 9        | 10 %   |
| от 10 и более    | 20 %   |

## Статусы велосипеда

| Статус        | Описание                          |
|---------------|-----------------------------------|
| available     | доступен для аренды               |
| rented        | выдан в аренду                    |
| maintenance   | на обслуживании                   |

## Статусы аренды

| Статус     | Описание                |
|------------|-------------------------|
| active     | аренда активна          |
| completed  | аренда завершена        |
| cancelled  | аренда отменена         |

## Алгоритм работы

1. Запускается `main()`, загружаются данные из JSON-файлов.
2. Выводится главное меню с доступными действиями.
3. Пользователь выбирает действие.
4. В зависимости от выбора:
   - выводятся типы велосипедов, станции или доступные велосипеды;
   - регистрируется новый пользователь;
   - оформляется аренда (выбор велосипеда, ввод ID пользователя, часов);
   - завершается активная аренда;
   - выполняется поиск аренд по пользователю;
   - выводится статистика по арендам;
   - добавляется новый велосипед или станция.
5. При оформлении аренды:
   - проверяется доступность велосипеда;
   - проверяется существование пользователя;
   - проверяется положительное количество часов;
   - рассчитывается базовая стоимость, скидка и итог;
   - вычисляется время начала и окончания аренды;
   - велосипед переводится в статус `rented`;
   - аренда сохраняется в JSON.
6. При завершении аренды:
   - статус аренды меняется на `completed`;
   - велосипед возвращается в статус `available`;
   - изменения сохраняются в JSON.
7. Все изменения данных фиксируются в соответствующих JSON-файлах.
