## Назначение
Приложение предназначено для автоматизации процесса аренды велосипедов:
учёта доступного транспорта, оформления аренды, расчёта стоимости и
возврата велосипеда.

## Описание предметной области
Предметная область — услуги краткосрочной аренды велосипедов.
Основные процессы:
- регистрация клиента;
- выбор велосипеда из доступного парка;
- расчёт стоимости аренды в зависимости от типа велосипеда и времени;
- выдача чека с информацией

## Основные сущности
- Велосипед —   тип (горный, городской, детский), цена за час.
- Клиент — имя, статус.
- Аренда — клиент, велосипед, время начала, время окончания, стоимость.
- Пункт проката — название, адрес, список велосипедов.

## Основные функции
- Просмотр списка доступных велосипедов.
- Оформление аренды велосипеда.
- Расчёт стоимости аренды.
